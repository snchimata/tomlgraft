# Brand assets

- [Logo](logo.png): transparent bracket-and-grafted-branch mark, 1254 × 1254.
- [Banner](banner.png): ivory README banner with the same mark and wordmark, 2172 × 724.

The README uses the banner. The standalone logo is available for project artwork;
its forest-green mark is best placed on a light background. Both PNGs are stored
locally so the README does not rely on a hosted image service.

## Creation prompts

Mode: built-in image generation. The banner used the final logo as its reference.

### Logo

```text
Use case: logo-brand
Asset type: transparent logo for the GitHub README of tomlgraft, a Rust TOML editor.
Primary request: a distinctive professional, crisp, vector-like brand mark that combines TOML square brackets with a grafted botanical branch. A single ascending forked stem joins cleanly at one visible graft seam, one small simple leaf, framed by two open square brackets. Make the whole silhouette read as one compact coherent software symbol, not a literal tree illustration.
Style/medium: precise flat geometric identity, clean rounded joins, refined editorial developer-tool brand. Restrained forest green with a small warm amber accent at the join, strong legibility on both light and dark backgrounds.
Composition/framing: square canvas, centered mark with generous even transparent margin, symbol fills about 65 percent of the image.
Constraints: transparent background, no text, no letters, no words, no gradients, no shadows, no mockup, no watermark, no surrounding presentation board. One final logo only.
```

### Banner

```text
Use case: ads-marketing
Asset type: GitHub README hero banner for tomlgraft, a source-preserving TOML editing tool.
Input image: reference logo. Use the exact bracket-and-grafted-branch symbol and its forest-green/amber colors as the brand identity.
Primary request: design a polished, restrained, wide software-project banner. Horizontal landscape, approximately 3:1 aspect ratio. Warm ivory background, forest-green typography, tiny amber accent. Typography-led editorial design with generous whitespace and very subtle green guide lines suggesting the source lines of a configuration file. Flat artwork, crisp edges.
Composition: left two-thirds contain a large lowercase wordmark "tomlgraft" in a confident clean modern sans serif; beneath it the exact tagline "Small edits. Clean diffs." in smaller highly readable type; then a small line "TOML  /  RUST  /  CLI  /  PYTHON". Right third contains the reference logo at large scale, entirely inside the canvas with ample clear margin. Avoid crowding the text. Keep important content in the central 85 percent so it scales well on a README.
Text (verbatim): "tomlgraft"; "Small edits. Clean diffs."; "TOML  /  RUST  /  CLI  /  PYTHON".
Constraints: one complete finished banner, no mockup, no presentation board, no extra logos, no performance claims, no badges, no additional text, no watermark, no photographic textures, no 3D, no dramatic gradients or glow. Background must be opaque ivory.
```
