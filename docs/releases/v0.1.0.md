# tomlgraft v0.1.0

Initial experimental release of the Rust core, local CLI, and CPython bindings
for small TOML and Python packaging metadata edits.

Use `set`, `rm`, dependency helpers, or versioned JSON batches. Preview first
with `--dry-run --diff`. Reports include commit state and durability. Equal edits
retain original bytes and target mtime; a failed batch rolls back.

Supported artifacts: Windows/Linux x86-64; CPython 3.12 wheels. Linux release
artifacts require glibc 2.35+. Source builds require Rust 1.89+. Writable targets
are existing regular files on local NTFS/ext4 under the documented restrictions.
Recognized lockfiles are read-only.

Windows directory durability is uncertain. Unqualified layouts/security metadata
are refused. Other editors can race the final recheck/rename. This release makes
no universal losslessness, resolver, installation, static-link, or latency claim.

Verify downloads against `SHA256SUMS`. See the
[examples](https://github.com/snchimata/tomlgraft/tree/main/examples),
[contract](https://github.com/snchimata/tomlgraft#preservation-and-metadata), and
[changelog](https://github.com/snchimata/tomlgraft/blob/main/CHANGELOG.md).
