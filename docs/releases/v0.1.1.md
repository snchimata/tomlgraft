# tomlgraft v0.1.1

Documentation and package metadata update for the experimental release.
Editing behavior, supported platforms, and safety limits are unchanged.

- Expanded PyPI README with runnable Python examples for in-memory patches,
  file previews, dependency edits, and PEP 723 metadata.
- Clearer Python/CLI installation guidance and absolute documentation links.
- Explicit preservation limits, commit/durability handling, and measured
  performance context.
- Synchronized Rust/Python package versions and installation references.

Artifacts target Windows/Linux x86-64 and CPython 3.12. Linux release artifacts
require glibc 2.35+; source builds require Rust 1.89+. Writes remain experimental
and limited to existing regular files on qualified local NTFS/ext4 targets.
Windows directory durability is uncertain. No new preservation, portability,
or latency guarantee is made.

Verify downloads against `SHA256SUMS`. See the
[Python API](https://github.com/snchimata/tomlgraft/blob/main/docs/reference.md#python-and-rust),
[file contract](https://github.com/snchimata/tomlgraft/blob/main/docs/reference.md#file-transactions),
and [changelog](https://github.com/snchimata/tomlgraft/blob/main/CHANGELOG.md).
